# Writeup For Assignment 1
My game is designed in a way that if a blue ball that player throws out hits the target, it will turn red. To achieve that, player needs to come up with specific, even relatively easy, strategy - adjusing the perspective and throwing balls in another angle. The consequence of the outcome is measureable as well. With the terrain I put in the game, player can see the red balls on the ground.

I tried out terrain in the unity primitives, and it was actually fun. So I made the scene into sort of like a valley in desert.

Writing the logic with ball collisions actually resonates me with a small dungeon game design I did in junior year. In Unity, it brings everything from 2D to 3D, which is really cool.
